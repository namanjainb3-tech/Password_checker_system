# 🔐 Password Security Checker System

## Overview

The Password Security Checker System is a desktop-based Python application developed using the Tkinter GUI framework. The project helps users evaluate the strength and validity of their passwords based on commonly accepted cybersecurity standards.

The system analyzes a user-entered password and verifies whether it satisfies essential security requirements such as minimum length, uppercase letters, lowercase letters, digits, and special characters. It also provides a strength assessment to help users create more secure passwords.

---

## Features

### Password Validation

The system checks whether the entered password:

* Contains at least 8 characters
* Includes at least one uppercase letter (A-Z)
* Includes at least one lowercase letter (a-z)
* Includes at least one numeric digit (0-9)
* Includes at least one special character (@, #, $, %, etc.)

### Password Strength Analysis

Based on the password composition, the system categorizes password strength as:

* Poor
* Intermediate
* Very Strong

### Interactive Graphical User Interface

Built using Python Tkinter, the application provides:

* User-friendly interface
* Real-time password submission
* Validation feedback messages
* Password strength indicator
